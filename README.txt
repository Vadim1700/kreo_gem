ABUZOK — локальный проект HTML/CSS/JavaScript

ЗАПУСК
1. Распакуйте ZIP-архив.
2. Откройте index.html в браузере. Сервер или установка не нужны.

УПРАВЛЕНИЕ СИГНАЛАМИ
- Значок ABUZOK вверху открывает увеличенное окно управления сигналами.
- Можно создавать любое количество сигналов, выбирать активный сигнал, редактировать и удалять его.
- Приоритет меняется прямо в строке сигнала; список автоматически перестраивается.
- Для каждого сигнала можно выбрать деревянную, каменную, железную, алмазную или случайную кирку, либо отключить кирку.
- Задайте количество золота, меди, алмазов, изумрудов, верстаков и ТНТ от 0 до 999.
- Сигналы сохраняются в localStorage этого браузера.

ОБЩИЕ НАСТРОЙКИ
- Кнопка с шестерёнкой внизу открывает отдельное окно настроек.
- Можно отключить анимацию генерации и скрыть счётчик онлайн.
- Общие настройки сохраняются в localStorage этого браузера.

ВАЖНО
Генерация является локальной демонстрацией в браузере. Проект не подключается к реальному игровому серверу и не отправляет игровые команды.
